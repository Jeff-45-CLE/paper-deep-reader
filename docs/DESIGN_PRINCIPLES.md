# Design Principles

## 1. Learning note first

The primary artifact supports understanding and later retrieval. Venue scoring remains optional.

## 2. Closed-loop method reconstruction

Module names alone do not explain an algorithm. The note must show how information moves and how the final output is produced.

## 3. Source-grounded interpretation

The paper, its figures, tables, equations, and appendix define the evidence boundary. Added explanation is useful only when its status is clear.

## 4. Original terminology as an interface

Technical terms and notation connect the note back to the paper, code, and later literature. The skill preserves them and explains them at first use.

## 5. Claims require evidence

A result table, theorem, ablation, or analysis must support each major claim. The note records both the evidence and the strength of support.

## 6. Experiments answer research questions

Dataset names and final scores have limited value without the question each experiment addresses. The output begins with RQs and maps results back to claims.

## 7. Examples must execute the real procedure

A worked example follows the algorithm order and reaches a final output. Invented values are labeled.

## 8. Missing information remains visible

The skill reports unavailable or ambiguous details. It does not replace them with plausible guesses.

## 9. Feishu-ready structure

Short sections, compact paragraphs, controlled tables, and local evidence anchors improve copy-paste use and long-term retrieval.

## 10. Language control is part of correctness

Generic AI phrasing often hides missing evidence or repeats content. The repository treats language style as a quality gate.

## 11. No separate memory checklist

The default output excludes “What to Remember.” The one-sentence summary, contribution analysis, results, and claim-evidence map already provide retrieval points.

## 12. Extensible single-paper core

Multi-paper review support is built as a matrix template. The core skill remains focused on accurate single-paper extraction.
