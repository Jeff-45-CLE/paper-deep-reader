# Roadmap

The roadmap records candidate directions. Items move only after a reproducible use case and evaluation example are available.

## v0.2 — Evaluation coverage

- Add open-paper examples from several research fields.
- Add regression tests for theoretical, systems, survey, optimization, and agent papers.
- Add false-positive tests for language rules.
- Add a compact scoring report generated from `eval/RUBRIC.md`.

## v0.3 — Paper and code alignment

- Map paper modules to repository files and symbols.
- Record missing implementation details.
- Compare stated pseudocode with executable code paths.
- Add a reproducibility-note template.

## v0.4 — Literature synthesis

- Merge single-paper notes into a normalized literature matrix.
- Build method taxonomies and evidence tables.
- Track conflicting protocols and incomparable results.
- Export citation metadata and BibTeX collections.

## Candidate extensions

- Feishu API export through an optional connector.
- Figure and table evidence index.
- Multilingual style-rule packs.
- Domain packs for machine learning, communications, robotics, and scientific computing.
- Human evaluation benchmark for method-flow completeness.
